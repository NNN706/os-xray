# os-xray 4.0.0

Один активный туннель Xray + tun2socks и полный JSON для каждого профиля. Внутри JSON могут находиться несколько outbounds, Routing, балансировщики, DNS, policy и observatory.

Реализация начата от коммита `dbaee5bd32ac75a0fe72de69fdbb19cea0715480`.

Редактор CodeMirror 6 поставляется локально: подсветка JSON, номера строк, сворачивание, поиск, форматирование, изменение высоты и синтаксические ошибки. Validate проверяет открытый текст, включая несохранённые изменения, установленным Xray-core.

Импорт поддерживает полный JSON, массив конфигураций, HTTPS-подписку и VLESS. Автообновление загружает подготовленный JSON и **никогда не перезапускает туннель**. Применение выполняется через Apply или ручное переподключение. Test использует действующий SOCKS и маршрутизацию, показывает HTTP-код и время до первого байта.

Подробности: [настройка и переход с прежней версии](docs/FULL_JSON.ru.md), [проверки и ограничения](docs/TESTING.md), [архив документации v3](docs/legacy/README-v3.ru.md).

Установщик требует уже установленные Xray-core, tun2socks и curl; ядро автоматически не скачивается и не заменяется. JavaScript-редактор включён в пакет, Node.js на OPNsense не требуется.

На сервер в рамках разработки ничего не развёрнуто. Проверки на настоящей OPNsense/FreeBSD ещё необходимы; симуляция запуска и отката не заменяет их.

Heartbeat / WAN bypass and isolated runner setup: [documentation](docs/HEARTBEAT.ru.md).
